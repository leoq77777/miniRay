# Benchmark 结论与验证

本次在 Apple M5 / macOS arm64 上完成 Release 实测。42 个配置各重复 5 次，共 210 个批次；每个常规批次 400 项。环境、源码及二进制 SHA-256、逐次命令与计数保存在 [raw.json](../benchmarks/results/2026-10-31/raw.json)。

正式数据包含 74,400 项实际任务与 2,000 次纯 RPC 查询。所有已接纳任务都完成，failed=0；另有 3,920 次预期的过载拒绝。故障场景共运行 320 项任务，包含 10 次 SIGKILL 注入，全部恢复完成。预热不包含在这些计数中。

完整表格见 [报告](../benchmarks/results/2026-10-31/report.md)，机器可读统计见 [summary.json](../benchmarks/results/2026-10-31/summary.json)，复现和指标定义见 [performance.md](performance.md)。

## 观察到的结果

| 观察项 | 各批指标的中位数 | 含义 |
|---|---|---|
| least-loaded，mixed，1 → 8 workers | 103.8 → 662.4 tasks/s，6.38× | 每 worker 固定 2 槽位，增加 worker 对该工作负载有效 |
| 同组 mixed p99 | 3755.90 → 448.81 ms | 协调器内部完成延迟降低，但仍包含整批排队 |
| least-loaded，uniform，1 → 8 workers | 139.0 → 944.5 tasks/s，6.80× | 固定 400 项，增加总槽位从 2 到 16 |
| rpc tiny/serial | p50 0.119 ms；p99 0.234 ms | 客户端调用至结果返回，无调度的 NOT_FOUND 查询 |
| remote tiny/serial | p50 14.306 ms；p99 16.087 ms | 客户端调用至结果返回，完整远程任务链路 |

tiny/burst 在两种策略、1–8 个 worker 下的吞吐大致维持在 2,930–3,044 tasks/s，增加 worker 没有带来对应收益。这表明该微任务实验主要受控制面或客户端开销影响，不能把更多 worker 直接解释为更高吞吐。local tiny 已接近时钟粒度，计时读取开销未扣除，只作为量级参照。

异构 1/2/4 容量下，mixed 的 least-loaded 吞吐中位数为 328.6 tasks/s，round-robin 为 329.0 tasks/s，差异很小。两种策略都跳过满载节点，当前数据不能支持 least-loaded 普遍优于 round-robin 的结论。

## 故障恢复

| 策略 | 重试决策观测 ms | 新代派发观测 ms | 选中任务完成观测 ms | 检测后至派发的等待 ms |
|---|---:|---:|---:|---:|
| least-loaded | 475.27 | 3959.41 | 4216.04 | 3498.49 |
| round-robin | 489.86 | 3959.92 | 4218.97 | 3470.06 |

设置为心跳 50ms、超时 500ms。检测在约半秒内完成，但选中任务需要约 4.2 秒恢复。根据运行时的 FIFO 实现，失败任务被放回等待队列末尾；同批其他任务仍在等待，存活 worker 仅有 2 个槽位。观测也显示大部分时间耗在检测后到新代派发之间，因此不能只优化心跳超时来解决恢复尾延迟。

以上三个观测均从 kill 返回计时，包括约 2ms 轮询与 RPC 误差，不是精确的服务端事件时间；新代派发仅表示它已离开 PENDING，不代表用户函数已开始。

## 背压

两种策略各 5 次过载实验都在 400 次提交中接纳 8 次、拒绝 392 次（98%），8 个接纳任务全部完成。此实验确认了真实 RPC 背压路径。接纳总量不等于瞬时队列峰值，未额外测量 RSS 或内存高水位。

## 后续优化应先验证什么

本次只完成测量，没有混入运行时优化。代码中的 10ms 空闲扫描、同步派发、全局状态锁以及单客户端同步提交/查询，都是需要 profiling 区分的候选开销。tiny/serial 的端到端延迟远高于单次纯 RPC，与固定扫描周期处在同一量级，但这不是单因素因果实验。后续可以分别比较通知唤醒与异步派发，再使用同一矩阵验证吞吐和 p99，避免仅凭某个局部耗时宣称优化效果。

数据仅适用于这台机器上的同机 sleep/echo 实验。未测试跨机网络、Linux、CPU 密集型任务或独占主机，五次重复也不足以保证其他硬件上的相同收益。
